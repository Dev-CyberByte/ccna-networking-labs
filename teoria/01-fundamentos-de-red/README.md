# 01 — Fundamentos de Red

Este módulo cubre los conceptos base que toda la certificación CCNA da por sentados.
Sin entender esto bien, los temas siguientes no tienen sustento.

---

## Contenido del módulo

| Archivo | Tema |
|---------|------|
| [modelo-osi.md](./modelo-osi.md) | Las 7 capas del modelo OSI y su función |
| [tcp-ip.md](./tcp-ip.md) | La pila TCP/IP y cómo se compara con OSI |
| [subnetting.md](./subnetting.md) | Subredes, VLSM y cálculo de direcciones |

---

## Objetivos de aprendizaje

Al terminar este módulo se debe poder:

- Explicar qué hace cada capa del modelo OSI y dar un ejemplo real
- Describir cómo viaja un paquete desde una app hasta el cable
- Identificar en qué capa opera cada protocolo (HTTP, TCP, IP, Ethernet)
- Calcular subredes con VLSM dado un bloque de direcciones
- Determinar dirección de red, broadcast, rango de hosts y máscara
