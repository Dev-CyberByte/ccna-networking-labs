# ccna-networking-labs
Este repositorio contiene laboratorios prácticos de redes basados ​​en temas de CCNA.  Incluye simulaciones con Cisco Packet Tracer y GNS3, así como escenarios de red inspirados en situaciones reales.


# Objetivo
Reforzar los fundamentos de redes
Practicar configuraciones reales
Crear un portafolio para puestos de Ingeniero de Redes / Junior
# Tecnologías
Cisco Packet Tracer
GNS3 (próximamente)
Linux (laboratorios futuros)
Protocolos de red (TCP/IP, OSPF, VLAN, DHCP, DNS)
# Temas cubiertos
Modelo OSI y TCP/IP
Subredes
VLAN
Enrutamiento (estático y dinámico)
NAT
DHCP / DNS
Conceptos básicos de seguridad de red
# Progreso
Topologías básicas
Laboratorios de subredes
Protocolos de enrutamiento
Laboratorios de GNS3
Laboratorio en casa
