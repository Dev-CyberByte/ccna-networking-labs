# CCNA Networking Labs

Repositorio personal de estudio, práctica y documentación para la certificación **Cisco CCNA 200-301**.

Cada tema cubre teoría explicada en mis propias palabras, laboratorios en Packet Tracer y GNS3, y proyectos de red diseñados como escenarios reales de empresa.

---

## Proyectos

Escenarios diseñados como redes de empresas reales. Cada proyecto incluye:
- Escenario de negocio y requerimientos
- Diseño y diagrama de red
- Direccionamiento IP completo
- Configuraciones y verificaciones
- Archivos `.pkt` listos para abrir

| Proyecto | Tecnologías principales |
|----------|------------------------|
| Empresa pequeña | VLANs, DHCP, NAT, ACLs |
| Empresa mediana | OSPF, NAT, ACLs, dos edificios |
| Campus universitario | Core/Distribution/Access, VLANs complejas |
| ISP simulado | BGP básico, múltiples clientes |
