# 📡 CCNA Networking Labs

Repositorio completo de estudio y práctica para la certificación CCNA.

## Estructura
- `teoria/` — Explicaciones teóricas por tema (manual de referencia)
- `labs-packet-tracer/` — Prácticas en Cisco Packet Tracer (.pkt)
- `labs-gns3/` — Las mismas prácticas en GNS3 (IOS real)
- `lab-casero/` — Pruebas con hardware físico real
- `proyectos/` — Escenarios de red tipo empresa
- `recursos/` — Comandos, cheatsheets, diagramas
